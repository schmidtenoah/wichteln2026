Wunschlisten verwalten

Mit dem Admin-Passwort aus dem Generator öffnest du alle Wunschlisten. Wer wen gezogen hat, siehst du hier nicht.

Wichteln Wunschlisten

    Wünsche

    Bild oder Link einfügen

    Hier klicken und Strg+V, oder ein Bild hierher ziehen. Im Shop „Bild kopieren“ → einfügen, dann den Link kopieren → einfügen: beides landet im selben Wunsch. Den Namen tippst du dazu.

      Noch keine Wünsche. Bild oder Link oben einfügen, einzeln hinzufügen oder die Nachricht unten reinkopieren.

      Aus einer Nachricht übernehmen

      Eine Zeile pro Wunsch. Preise wie „25 €“ und Links werden automatisch erkannt.

      So sieht es der Wichtel

      Die Vorschau zeigt genau den Zettel, der aus dem Geschenk steigt. Tipp auf Bild oder Namen öffnet dort den Link.

      Einstellungen

      Direkt auf GitHub veröffentlichen

      Optional. Dann reicht ein Klick auf „Veröffentlichen“, und die Seite ist nach etwa einer Minute aktuell. Ohne diese Angaben lädst du die Datei herunter und lädst sie selbst hoch.

      Sicherung

      Die Sicherung enthält alle Wünsche im Klartext, aber keine Auslosung. Brauchst du, falls du neu auslosen musst: node tools/generate.mjs --force --wishes sicherung.json
